## Introduction

On a cold July morning the temperature in Nyanga might be $-4^\circ\text{C}$ while Harare is $3^\circ\text{C}$ and Chimanimani is $-1^\circ\text{C}$. Which town is coldest? A shop offers $\frac{3}{5}$ off one item and $58\%$ off another. Which discount is bigger? To answer you must compare numbers written in different forms.

You should already be able to convert fractions and percentages to decimals.

## Key definitions

:::definition{term="Ascending and descending order"}
Ascending order runs from the smallest to the largest; descending order runs from the largest to the smallest.
:::

:::keyfact{title="The order symbols"}
| Symbol | Meaning | Example |
| :---: | --- | --- |
| $=$ | is equal to | $0.5 = \frac{1}{2}$ |
| $\neq$ | is not equal to | $0.67 \neq \frac{2}{3}$ |
| $<$ | is less than | $-5 < -2$ |
| $>$ | is greater than | $0.66 > 0.606$ |
| $\leq$ | is less than or equal to | $x \leq 4$ includes 4 |
| $\geq$ | is greater than or equal to | $x \geq -1$ includes $-1$ |
:::

The narrow end of $<$ or $>$ always points to the smaller number.

## Negative numbers

On a number line, numbers increase from left to right. A negative number with a **larger** size is **further left**, so it is **smaller**: $-7 < -3$, just as $-7^\circ\text{C}$ is colder than $-3^\circ\text{C}$.

:::worked-solution[Example 1: put $2,\ -3,\ 0,\ -7,\ -1.5$ in ascending order]
1. The negative numbers come first, the most negative first: $-7$, then $-3$, then $-1.5$.
2. Then zero, then the positive number.
3. Ascending order: $-7,\ -3,\ -1.5,\ 0,\ 2$.
:::

## Decimals

Line the numbers up by the decimal point and compare digit by digit from the left. Filling the gaps with zeros helps.

:::worked-solution[Example 2: put $0.6,\ 0.606,\ 0.66,\ 0.06$ in ascending order]
1. Write each with three decimal places: $0.600,\ 0.606,\ 0.660,\ 0.060$.
2. Compare: $0.060 < 0.600 < 0.606 < 0.660$.
3. Ascending order: $0.06,\ 0.6,\ 0.606,\ 0.66$.
:::

A longer decimal is not necessarily bigger: $0.606 < 0.66$.

## Mixed forms

When fractions, decimals and percentages are mixed, convert them all to decimals (or all to percentages), order them, then write the answer using the **original** forms.

:::worked-solution[Example 3: put $\frac{3}{5},\ 0.62,\ 58\%,\ \frac{5}{8}$ in ascending order]
1. Convert: $\frac{3}{5} = 0.6$, $0.62$, $58\% = 0.58$, $\frac{5}{8} = 0.625$.
2. Order the decimals: $0.58 < 0.6 < 0.62 < 0.625$.
3. Write the original numbers: $58\%,\ \frac{3}{5},\ 0.62,\ \frac{5}{8}$.
:::

:::worked-solution[Example 4: which symbol goes between $\frac{2}{3}$ and $0.67$?]
1. $\frac{2}{3} = 0.6666\ldots$ and $0.67 = 0.6700$.
2. Compare the third decimal place: $6 < 7$, so $\frac{2}{3} < 0.67$.
3. It is also true that $\frac{2}{3} \neq 0.67$.
:::

To compare two fractions without decimals, write them with a common denominator: $\frac{3}{4} = \frac{9}{12}$ and $\frac{2}{3} = \frac{8}{12}$, so $\frac{3}{4} > \frac{2}{3}$.

## Common mistakes

:::mistake{title="Ordering negative numbers by their size"}
$-8$ is **less** than $-3$, even though 8 is greater than 3. Think of temperatures: $-8^\circ\text{C}$ is colder.
:::

:::mistake{title="Thinking more decimal places means a bigger number"}
$0.606 < 0.66$. Compare place by place, not by the number of digits.
:::

:::mistake{title="Giving the converted forms in the answer"}
If the question lists $\frac{5}{8}$ and $58\%$, your ordered list must show $\frac{5}{8}$ and $58\%$, not $0.625$ and $0.58$.
:::

:::mistake{title="Mixing up < and ≤"}
$x < 3$ does not include 3; $x \leq 3$ does. For integers, $-2 < n \leq 3$ means $n = -1, 0, 1, 2, 3$.
:::

## Exam tips

:::exam-tip
Show the decimal you converted each number to. If you make an ordering slip, the conversions can still earn a method mark.
:::

:::exam-tip
Read whether the question asks for ascending (smallest first) or descending (largest first) order, and write the word "smallest" over your first number as a check.
:::

## Summary

:::summary
- Numbers increase from left to right on a number line, so $-7 < -3 < 0$.
- Compare decimals place by place after lining up the decimal points.
- Convert mixed forms to decimals, order them, and answer with the original forms.
- $<$ and $>$ are strict; $\leq$ and $\geq$ include the end value; $\neq$ means "is not equal to".
:::
