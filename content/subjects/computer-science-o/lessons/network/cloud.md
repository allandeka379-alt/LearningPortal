## Introduction

Farai writes his history project on a school computer in Kwekwe, saves it, and that evening carries on editing the same file on his phone at home. He never copied it to a flash drive. His file is stored **in the cloud**: on servers owned by a cloud provider, which he reaches over the internet from any device.

Cambridge 0478 (topic 3.3) asks what cloud storage is and the advantages and disadvantages of storing data in the cloud compared with storing it locally. ZIMSEC Form 3 asks you to explain the concept of cloud computing services. The classic exam question is "compare cloud storage with local storage for this person or business".

## Key definitions

:::definition{term="Cloud storage"}
A method of storing data on remote physical servers, owned and managed by a cloud provider, which the user reaches over the internet.
:::

:::definition{term="Local storage"}
Storing data on a device the user owns and has with them or on their own premises, such as the computer's own hard disk or solid-state drive, a USB flash drive or an external drive.
:::

:::definition{term="Cloud computing"}
Using computing services, such as storage, software and processing power, provided over the internet by remote servers instead of by the user's own computer.
:::

## What is "the cloud"?

The cloud is not in the sky. It is made up of **real physical servers** in large buildings called data centres, often in other countries. Each data centre holds thousands of servers with hard disks and solid-state drives, backup power and cooling. Your data is usually copied onto several servers, sometimes in different data centres, so a single faulty drive does not lose it.

You reach these servers over the internet, through a website or an app, and the provider looks after the hardware, the backups and the security.

## Types of cloud service

| Service | What the user gets | Example uses |
|:--|:--|:--|
| Cloud storage | Space to store and share files online | Saving photos from a phone automatically; sharing a folder of school notes |
| Software as a service (SaaS) | Applications that run in a web browser, with nothing installed | Online word processors and spreadsheets, web-based email, online accounting |
| Platform as a service (PaaS) | A ready-made platform on which developers build and run their own applications | A developer in Harare building a booking app without buying servers |
| Infrastructure as a service (IaaS) | Rented virtual servers, storage and networking | A company running its website on rented servers instead of its own |

Cloud services are usually paid for by subscription (a monthly fee), often with a free allowance of storage.

:::worked-solution[How many photos fit in a cloud storage plan?]
Tendai's free cloud plan gives 5 GiB. Each photo from his phone is 4 MiB. How many photos can he store?

1. Convert the plan to MiB: 1 GiB = 1024 MiB, so 5 GiB = 5 × 1024 = 5120 MiB.
2. Divide by the size of one photo: 5120 ÷ 4 = 1280.
3. He can store 1280 photos. Higher-resolution photos or videos would fill the plan much faster, which is why providers sell larger plans.
:::

## Cloud storage compared with local storage

### Advantages of cloud storage

- Files can be **accessed from anywhere**, on any device with an internet connection.
- Files are easy to **share** with other people, who can even edit the same document together.
- The provider makes **backups** and copies data to several servers, so data survives if the user's own device is lost, stolen or broken.
- Storage can be **increased** at any time by paying for a bigger plan, without buying new hardware.
- The user does not have to buy, maintain or replace storage hardware.

### Disadvantages of cloud storage

- **No internet, no files**: if the connection fails, or the user has no data, the files cannot be reached.
- Uploading and downloading large files is slow on a low-bandwidth connection and uses **data**, which costs money.
- **Security and privacy**: data is held by a third party, possibly in another country; it could be exposed if the provider is hacked or an account password is stolen.
- The user depends on the provider: a subscription must be paid, and if the provider closes or loses data, the user cannot do anything about it.
- Ongoing cost: subscriptions continue for as long as the files are stored.

### Local storage in comparison

Local storage works without an internet connection, gives fast access, and keeps the user in full control of the data. However, the user must make their own backups, a lost or broken device can mean lost data, and files can only be used where the device is.

:::example
**Recommending storage for a small accounting firm.** An accounting firm in Gweru keeps its clients' financial records. Its staff often visit clients and need the files on their laptops. Power cuts sometimes knock out the office internet connection.

- Cloud storage would let staff open files at clients' premises and would protect the records if a laptop were stolen, because the provider keeps backed-up copies.
- But the records are confidential, so the firm must check where the provider stores data and protect accounts with strong passwords and two-step verification. In Zimbabwe, the Cyber and Data Protection Act requires personal data to be kept secure.
- Because the internet connection is unreliable, the firm should also keep local copies of the files it is working on.
- A sensible recommendation is a **combination**: cloud storage for sharing and off-site backup, plus local copies for working offline.
:::

## Common mistakes

:::mistake{title="Saying cloud storage has no physical hardware"}
Cloud data is stored on **physical servers** in data centres. "Cloud" only means the user does not see or manage them.
:::

:::mistake{title="Saying the cloud is completely secure"}
Providers use strong security, but accounts can still be hacked, passwords stolen or providers breached. The user is also trusting a third party with the data.
:::

:::mistake{title="Forgetting the internet connection"}
Every cloud advantage depends on an internet connection. Always mention the connection when you list the disadvantages.
:::

## Exam tips

:::exam-tip
In a "compare" question, write matching pairs: "cloud: reached from anywhere with internet; local: only on the device, but works without internet". One-sided lists earn fewer marks.
:::

:::exam-tip
Tie each point to the scenario: a student who changes devices benefits from access anywhere; a business with confidential data worries about security; someone with poor connectivity worries about access.
:::

:::keyfact{title="ZIMSEC and Cambridge"}
Cambridge concentrates on cloud **storage** and its comparison with local storage. ZIMSEC asks about cloud computing **services** more widely, so learn the SaaS, PaaS and IaaS examples too.
:::

## Summary

:::summary
- Cloud storage keeps data on remote physical servers owned by a provider and reached over the internet.
- Cloud services include storage, software as a service, platform as a service and infrastructure as a service.
- Advantages: access from anywhere, easy sharing, provider backups, scalable storage, no hardware to maintain.
- Disadvantages: needs an internet connection and data, security and privacy concerns, dependence on the provider, ongoing fees.
- Local storage works offline and keeps control with the user, but the user must make backups and the files stay on the device.
:::
